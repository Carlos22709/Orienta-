# Orienta+ — instrucciones para Claude Code

Lee y aplica, en este orden:

1. `AGENTS.md`, que contiene las reglas canónicas de trabajo del repositorio.
2. `PROJECT_CONTEXT.md`, que contiene el contexto funcional, académico, legal y de accesibilidad.
3. El código, pruebas y documentación relevantes para la tarea actual.

No trates propuestas técnicas pendientes como decisiones aprobadas. Conserva cambios ajenos, no inventes evidencia y no realices commits, pushes, despliegues ni operaciones externas sin solicitud explícita. Comunícate en español salvo indicación contraria.
